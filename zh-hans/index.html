产品组合

10多款消费产品

7年间覆盖交易平台、AI应用、创作者工具、移动增长、无服务器基础设施和真实运营。有些成功，有些失败，但每个产品都留下了经验。

电商增长

TikTok CPI 0.09美元，付费CAC 8美元

问题： 消费电商漏斗利润率很薄，常规CAC算法无法反映真实情况。

结果： 直播电商实验实现TikTok CPI $0.09、每位买家付费CAC $8，并完整记录单位经济模型。

生产级AI

2天上线Stable Diffusion API

问题： 竞争对手推出AI图像产品时，我们还没有后端，两周的开发周期太长。

结果： 生产API在48小时内上线至无服务器AWS。真正困难的不是构建，而是上线后的所有运营工作。

基础设施

适合小团队的无服务器架构

问题： 小团队无法为10多款产品分别承担沉重的基础设施。

结果： 从Hypee到cheap.market反复使用Lambda/DynamoDB/S3技术栈。我现在仍亲自编写生产代码。

市场研究

在创建公司的间隙，我会系统拆解整个创投市场，寻找下一次机会。

每个月，我都会按阶段、商业模式、变现方式、资本密集度和地区整理能找到的每一笔融资。不是为了报道新闻，而是回答一个问题:资金正流向哪里，又没有流向 哪些方向，这为新的产品留下了什么机会？

它起初只是我为选择第三家公司所做的研究，后来成为值得分享的资料。
