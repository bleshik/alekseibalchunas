Notes

Snapshot: 6 September 2026. Scores and measured API cost come from Artificial Analysis Coding Agent Index v1.4.

Codex estimates: Credits applies the working 20% discount. Pro 20x assumes included compute delivers about 1.6x to 2.0x the value of base pay-as-you-go credits. Neither is an official per-task quote.

DeepSeek on OpenRouter: Flash 0731 currently starts near $0.05/M input and $0.10/M output, versus DeepSeek Direct at $0.22-$0.44/M fresh input and $0.66-$1.32/M output. The table keeps the measured $0.06 benchmark task cost because no identical token trace has been rerun through OpenRouter. See current OpenRouter endpoints.

Missing current models: Grok 4.6 and Claude Sonnet 5 have CursorBench results, but no comparable Coding Agent Index v1.4 run yet. Mixing those scores into this ranking would make the decision less reliable.
