01

My routing guide

Benchmarks are useful only when they change a decision. This is the model ladder I would use today.

Cheap, testable work

Luna Max

Bounded implementation, repository checks, and diagnostics with cheap verification. It reaches 57 for $0.29 per task.

Best value step-up

Terra Max

Use when Luna misses or the change spans several moving parts. Score 60 at $1.93 per task.

Reliable default

Sol High

Important multi-file implementation and debugging. High scores 64 at $3.00; Max adds one point for another $2.00.

Hardest work

Astra Max

Use when failure is expensive or the task needs long-horizon judgment. It scores 67 at $4.72 and uses far fewer tokens than Sol Max.

Claude default

Opus 5 High

Use when Claude Code is the better harness or you want Claude's coding style. Score 66 at $3.92.

Maximum quality

Fable 5.1 Max

The current leader at 70. It costs $9.18 per task, so reserve it for work where the premium matters.

Caveat: Grok 4.6 looks unusually strong for its price in CursorBench 3.2, but it has no result yet in the comparable Coding Agent Index v1.4 table. I would test it, not crown it.

Method and sources

Snapshot: 6 September 2026. This is maintained periodically, not a live feed.

Primary benchmark: Artificial Analysis Coding Agent Index v1.4. Cost includes token pricing, cache reads, cache writes, and applicable discounts for the observed run.

Current-model cross-check: CursorBench 3.2. Compare only within its own table.

Official rates: OpenAI, Anthropic, Cursor, DeepSeek, and Kimi.

Interpretation: model, effort, and harness form one tested unit. A harness change can move the result more than a model revision. Use production acceptance tests for final routing decisions.
